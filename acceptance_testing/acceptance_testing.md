# Acceptance Testing

## Objective

Acceptance testing verifies whether the Student Dropout Risk
Prediction System satisfies the expected user and project
requirements.

## Acceptance Criteria

- User can enter student details.
- Student details can be stored.
- Saved students can be retrieved.
- Trained machine learning model can be loaded.
- Dropout risk can be predicted.
- Risk is displayed as LOW, MEDIUM, or HIGH.
- Performance score is calculated.
- Recommendations are generated.
- The complete prediction flow works successfully.

## Acceptance Test Cases

| Test Case | User Requirement | Expected Result | Status |
|-----------|------------------|-----------------|--------|
| Student Details | Enter student information | Details accepted | Pass |
| Save Student | Save student data | Data stored successfully | Pass |
| Student List | View saved students | Students displayed | Pass |
| Model Loading | Load trained model | Model loaded | Pass |
| Risk Prediction | Predict dropout risk | LOW/MEDIUM/HIGH displayed | Pass |
| Performance Score | Calculate student score | Score between 0 and 100 | Pass |
| Recommendation | Provide suggestions | Recommendations displayed | Pass |
| Complete System | Use complete application | Expected result generated | Pass |

## User Acceptance

The system provides a simple interface for entering student
details, selecting saved students, predicting dropout risk,
viewing performance scores, and receiving recommendations.

## Result

The acceptance tests confirm that the system satisfies the
major functional requirements of the Student Dropout Risk
Prediction System.

## Conclusion

The Student Dropout Risk Prediction System is acceptable for
the defined project requirements because the required student
management, prediction, scoring, and recommendation features
are successfully implemented.
